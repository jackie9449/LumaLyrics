使用 scripts/common.ps1，执行完整单元测试，再以新建程序目录外的 --data-dir 运行 --verify-ui <report> --verify-library-workspace --exit-after-capture。该专项保留原有导航、自动接收、独立译文开关和六主题 640/820/980/1220 宽度断言。另运行 --verify-translations 和 --verify-library-browser；核对 ui-check.json 中所有布尔值。

独立运行包由 scripts/publish-ui.ps1 -PreviewLabel library-sync 创建，先检查软件分发边界，再核验 ZIP 全部文件散列。
