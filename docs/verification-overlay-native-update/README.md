# 悬浮工具栏与新版 Apple Music · 2026-11-09

新增横向居中，保留物理纵向坐标并记住位置。功能和播放工具栏的颜色、字体及圆角资源限定在浮窗内，从当前悬浮外观生成，低对比度按钮文字采用可读颜色；主题、减少动画及关闭动画设置独立生效。播放条优先在歌词下方，靠近底部时直接放在上方，功能栏进一步避让。自定义弹窗回调使用物理像素，对另一工具栏的布局尺寸显式换算 DPI。

悬浮主窗口在 WM_WINDOWPOSCHANGING 中限制实际移动与尺寸，在恢复、显示、外观、DPI 和显示器变化后再次核对工作区及尺寸限制。边界使用当前显示器的工作区，支持负坐标；超宽窗口限制到可用宽度。关闭时取消排队的几何刷新，保留原有玻璃宿主、点击穿透、位置记忆及独立外观编辑流程。

## 隔离验证

使用 scripts/common.ps1 选择 bundled SDK，Release 构建零警告、零错误；单元测试 469/469（Core 92、Infrastructure 377），包含新增九个屏幕边界、负坐标居中和工具栏布局案例。

增强 --verify-overlay-transport 检查底部播放条邻接、两条不重叠、按钮触发横向居中及纵向坐标不变、位置记忆、实际窗口越界／超宽约束、窄窗顶部排列、八套悬浮主题自定义配色和六套应用主题隔离；保留串行单次媒体命令、减少动画、锁定／纯音乐／编辑／隐藏抑制和时钟清理检查。当前屏幕为 150% 缩放。原创文字截图只渲染本产品控件，使用实际控件位置组合检查排列；玻璃真实帧另由 --verify-glass-backdrop 验证，不能用合成图推断模糊效果。

增强 --verify-playback-sidebar 的原生就绪 fixture：准确资料库组展开后能找到 Songs、保留歌单组折叠、不把已展开组切回关闭、取消前不展开。保留延迟筛选框、全局搜索保护、迟到请求和窗口所有权检查。

最终运行包专项结果：悬浮控制 45/45、外观调整 45/45、移动 8/8、主题隔离 156/156、玻璃真实帧 62/62、队列侧栏及原生就绪 104/104、资料库工作区 115/115，共 535/535。顶部窄窗额外核对两条工具栏在有空间时均不遮挡歌词，底部仍保持紧邻和互不重叠。旧版汉堡菜单展开后的 15 秒兼容等待继续保留。已查看暖纸／玻璃主题底部排列的实际控件组合图。分发测试通过 2 个软件样例与 69 类私人文件拒绝案例，最终 ZIP 的 866 个文件集合、逐文件散列及 SHA-256 sidecar 核对一致。

复现：软件目录外新建 --data-dir，使用 --verify-ui <报告目录> --verify-overlay-transport --exit-after-capture。其它专项参数为 --verify-overlay-adjustments、--verify-overlay-motion、--verify-overlay-isolation、--verify-glass-backdrop、--verify-playback-sidebar。检查报告内布尔值与图像，不只依据退出码。

## 当前真实客户端

本机安装 Apple Music 1.1792.39682.0。原生观测确认 Sidebar_Header_Library 是收起的可展开组，因此旧逻辑无法发现「歌曲」。新逻辑只展开这一准确 ID，保留旧版导航／汉堡按钮兼容分支。实测单曲流程成功展开、选择「歌曲」、定位 FilterTextBox、核对唯一录音行并执行一次原生播放命令；新鲜系统媒体状态确认所选录音正在播放。原筛选已恢复，确认后客户端最小化，测试结束恢复暂停。

本次不把单曲实测推广为整张专辑、歌单续播、插播、队列跳转或拖动均已在新版验证。另一次被动队列读取未得到可用快照，因此没有为额外测试改动未知队列。共用单曲导航入口的专辑和插播获得展开组修复，其余命令和确认逻辑保持原样；对应单元及隔离就绪回归通过，仍保留各操作的现场验证限制。

真实客户端诊断、媒体录音信息、截图及测试资料全部保存在仓库与软件目录外的个人 QA 目录，不包含在 Git 或包内。没有修改用户歌词、翻译、任务或备份资料。运行包以 scripts/publish-ui.ps1 -PreviewLabel overlay-native-update 生成，不替换既有 v1.1.0 正式资产。
