## 安装与启动

[安装检查](installer-check.json)覆盖：当前用户注册、准确的中文桌面名称、启动目标和图标、开始菜单、全部软件文件 SHA-256 一致、重复安装、从包含中文与空格的路径运行新 EXE、安装后界面检查、卸载移除程序及注册、移除快捷方式、保留软件之外的原创个人资料样例。验证安装到独立目录；如已有正式安装，脚本会拒绝覆盖，已有同名桌面快捷方式会备份并恢复。

启动器由 Roslyn 确定性编译，引用 Windows 自带 .NET Framework 4 的基础程序集，真实应用由随包 Microsoft host 与 .NET 10 运行时启动。入口不需要 VBScript，旧 Launch.vbs 继续保留。安装器由官方签名有效的 Inno Setup 6.7.3 编译，主程序及最终安装器未进行代码签名。

## 分发边界

分发检查接受 2 类软件样例，拒绝 39 类私人文件。公开图片为自写文字和原创界面素材；软件包不含个人歌词、译文、封面缓存、媒体库、诊断资料或模型。安装、便携和卸载使用同一软件／个人资料边界。

可用 `scripts/test-installer.ps1 -Installer <安装EXE> -PackageDirectory <便携目录>` 验证安装及专项，`-FullUi` 运行完整界面回归，`-SkipUi` 只执行文件与系统登记检查。检查目录位于 `%LOCALAPPDATA%/LumaLyrics-InstallerChecks`，不会更改当前个人资料位置。
