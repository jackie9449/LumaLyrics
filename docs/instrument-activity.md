# 实验乐器活动显示

当前版本已在播放页加入乐器图标和 Settings 的「乐器识别」页，默认关闭。新增**通用多乐器实验**，按歌曲音频尝试 19 类乐器，不再将本曲清单限制为吉他、贝斯、鼓。清单只显示检出的类别，允许同时亮起；另保留古典室内乐弦乐兼容模型。它不会区分乐器件数、演奏者或逐个音符，管弦乐实测仍有明显误报和漏报，**完整配器准确度与进入／退出未验收**。范围、失败样例及来源见[按歌曲清单说明](instrument-roster.md)，旧三类结果见[历史摇滚实验](instrument-rock.md)。

## 本机使用

本次开发已自行下载并校验模型和公开测试集，并把固定版本的实验模型安装到当前选定的个人资料目录。退出旧程序后打开本次 `song-instruments` 便携预览，在 **设置 → 乐器识别** 选择通用模型，再打开「在播放页显示实验乐器识别」，播放 Apple Music。旧摇滚三类设置迁移到通用，显式弦乐选择保留，已有开关值不变；新资料默认关闭。切模型会清除本次录音绑定并取消旧回调。

「准备本机已下载模型」会查找开发工具的个人导出目录；未找到时可选择经过校验的 ONNX。只接收代码清单固定的版本、长度和 SHA-256，不能换成任意同名模型。其他电脑目前需要按[通用模型说明](instrument-roster.md)的命令生成该固定模型，再在设置中导入；弦乐兼容模型见[原验证记录](instrument-evaluation.md)。应用没有一键公网 ONNX 下载入口。通用转换模型约 307.5 MiB，弦乐兼容模型约 15.3 MiB，保存在个人目录的 `models/instruments/`，不装入软件目录，不随软件 ZIP 或个人备份分发。

图标含义：

| 状态 | 显示与含义 |
| --- | --- |
| 正在演奏 | 强调色亮起；是模型对一个时间窗口的判断 |
| 当前未活动 | 暗色；模型已将该类别加入本曲清单，当前未达到活动阈值 |
| 当前未识别 | 虚线图形；音频或时间覆盖不足，不能判断没有演奏 |
| 尚无完整清单 | 实时结果逐步积累，不在第一次听到整首前声称清单完整 |
| 暂停 | 已知图标变暗；继续播放后重新积累音频上下文 |
| 无有效信号／不支持 | 显示状态文字，不假亮，不自动切换系统混音或麦克风 |

通用模型需要 3055 ms、弦乐兼容模型需要约 975 ms 音频上下文，另有采集分包、计算、连续活动确认和 120 ms 图标渐变。它不是零延迟频谱灯。短暂音符和快速进入／退出可能合并；目前不承诺精确音符边界。

## 开头即显示完整暗色清单

在设置选择**完整单曲 WAV** 并预分析，完成后核对它与当前 Apple Music 是同一次演奏、同一剪辑的录音版本，再选择「将上次分析绑定到当前播放版本」。应用核对当前会话、代次、修订和时长，最终的录音版本确认由用户作出。绑定后，整曲中检出的受支持乐器从开头就列出；当前活动随播放位置亮起。

绑定仅对本次播放版本有效，切歌即解除。当前媒体会话没有可靠的持久录音 ID，因此**不会按歌名自动复用文件分析**，也不会把时长接近当作录音相同。整张 CD 的 WAV 尚不能借用到其中一首 Apple Music 单曲；CUE 分轨与自动精确身份连接尚未实现。完整覆盖表示全部采样已处理，不等于模型识别了所有实际乐器。

支持 RIFF PCM16、PCM24、IEEE float32（含相应 extensible 子格式），1–8 个普通声道、8–192 kHz；多声道使用已明确的全声道算术平均，不承诺杜比空间音频通道语义。RF64、压缩 WAV、FLAC／MP3／M4A 暂不支持。文件只读打开，前后核对内容 SHA-256；不改原音乐，不保存原始 PCM。选择文件分析时显示进度，可取消；离开该设置页会取消未完成的文件准备，不覆盖以前完成的缓存。

## 运行、清理和限制

需要 Windows build 20348 以上的 x64 系统及可取得的 Apple Music 同包音频渲染进程。程序核对当前媒体会话与活动渲染者，只采集指定应用；不激活、最小化或发送播放指令。采集在独立辅助进程中运行，停止超过期限只关闭本次拥有的辅助进程。缺少媒体会话或有效信号时给出明确状态；这不能直接解释为 DRM。

默认在播放页隐藏、窗口最小化或进入托盘时停止实时分析。独立的「隐藏播放页或最小化后继续分析」开关允许继续；关闭总开关和退出应用始终取消。音频窗口队列有界，积压时舍弃旧窗口，切歌、暂停、跳播和音频断续都会拒绝旧结果。

「清理乐器分析缓存」只清除乐器分析，不删除原始音乐、歌词、封面或模型。个人备份包含一致的 `instruments.db` 与可阅读分析 JSON；恢复只到新目录。录音绑定和模型版本始终隔离，分析不会改变纯音乐判定、歌词、翻译或悬浮歌词样式。

验证数据、准确率、数值误差和未完成项目见[执行与验证记录](instrument-evaluation.md)。公开 UI 截图／状态测试使用原创夹具，不作为音乐识别成功的证据。
