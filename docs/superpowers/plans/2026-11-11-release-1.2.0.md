# LumaLyrics 1.2.0 Release Implementation Plan

> Execute inline under the owner's explicit request to publish 1.2 on GitHub. The GitHub plugin supplies repository metadata; its current tools do not expose Release creation or asset upload, so use the existing authenticated GitHub release API workflow for those steps. Preserve all unrelated files and old releases.

**Goal:** Publish current main as stable v1.2.0 with verified Windows x64 portable and installer assets and SHA-256 files.

**Architecture:** Keep the existing central version, self-contained payload, Microsoft host launcher and Inno installer. Freeze tested application binaries while completing validation documents. Publish a draft only after local checks, upload and verify exact assets, then make it stable/latest.

**Tech Stack:** Bundled SDK 10.0.402 through scripts/common.ps1, locked offline NuGet feed, WPF isolated checks, signed existing Inno Setup 6.7.3, Git, GitHub plugin and REST release API.

**Spec:** User request: “发一个1.2版本的release”, with GitHub explicitly selected. Baseline b0736aa9689620dc4880263a582c3ab9db5d0daf; behavior baseline 441c37d. AGENTS.md permits GitHub changes when explicitly requested.

## Constraints

- Keep personal data, developer archives, .tools, caches, models, credentials and raw native diagnostics out of Git and release assets.
- Keep SDK, dependency versions and current product behavior; version changes belong in Directory.Build.props.
- Use new software-external --data-dir directories. Isolated UI success does not establish live Apple Music compatibility.
- Preserve v1.0.0/v1.1.0 tags and assets; no force push. Check remote state before publication and verify exact remote commit/tree afterward.

## Commands and deliverables

Use Invoke-Dotnet restore --locked-mode with the explicitly selected local feed and quoted '-p:NuGetAudit=false'; disabling online audit for that restore does not assert a current vulnerability audit. Build with Invoke-Dotnet build -c Release --no-restore, test with Invoke-Dotnet test -c Release --no-build --no-restore. Keep test reports outside software archives.

Outputs: artifacts/LumaLyrics-1.2.0-portable-win-x64.zip, artifacts/LumaLyrics-1.2.0-setup-win-x64.exe, corresponding .sha256 files and artifacts/release-1.2.0/SHA256SUMS.txt. Use API request bodies from exact UTF-8 files; credentials stay in process memory and are never printed or included in state files.
