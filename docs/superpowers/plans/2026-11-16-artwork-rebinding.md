# 音乐库封面重新关联计划

**目标：** 修复原生歌曲 ID 变化后专辑封面全部缺失的问题。

**依据：** `docs/album-artwork-audit-2026-11-16.md` 与仓库 AGENTS.md。

**设计：** 浏览器保持只读。按当前原生歌曲/已确认专辑封面来源，计算既有缓存键；校验缓存图片的散列和尺寸后供界面使用。没有缓存时可读取原生本地图片。无原生来源时保留原有精确歌曲关联，不进行名称猜测，不启动下载或解除暂停。
