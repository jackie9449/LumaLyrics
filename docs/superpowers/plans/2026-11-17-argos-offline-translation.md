# Argos 离线基础机翻执行计划

**目标：** 没有本地 agent 的用户可在应用内为当前歌曲或所选歌曲生成基础中文译文，作为缺少已有/AI 译文时的兜底。

**架构：** WPF 控制后台 coordinator，.NET 工作流核对原词/录音/修订并持久化；独立 Python 子进程只接收待译组，使用 Argos Translate 1.11.0 的 Package/Tokenizer 与 CTranslate2 4.6.0 CPU 推理。歌词已有分组，不加载高层自动分句的 Stanza/Torch 依赖。首版只开放官方直接英→中包，其他语言明确不支持，不自动转译。工具/模型存放机器本地工具目录，译文/队列仅存个人资料。

**资料：** 官方 Argos 文档 https://argos-translate.readthedocs.io/en/latest/ 、PyPI 1.11.0 与 argosopentech/argospm-index。固定下载清单与 SHA-256；不从运行时安装 pip、不修改系统 Python。开发期间下载只用于原创夹具实测，禁止发送用户歌词。

## 1. 引擎准备与协议
- [x] 创建公开组件锁文件（HTTPS、字节数、SHA-256、版本/来源），包含 Python Windows embedded、最小 wheels、英→中模型；组件不进入 Git/软件 ZIP。生成可重现刷新脚本和许可说明。
- [x] 实现安装器：显式按钮触发、取消/超时、散列验证、安全解压、临时目录完成后原子切换；损坏/中断不标为可用。支持读取已就绪状态，不在翻译时下载。
- [x] 实现 JSONL 子进程协议：stdin 输入，stdout 按输入顺序返回译文；禁止网络、CPU 单进程/有界线程、超时/取消时杀子进程，结束释放模型。只用当前确切分组，不增加时间戳，长组明确失败而非截断。

## 2. 工作流和数据保护
- [x] 使用既有动态原词与哈希，保留空白/中文行、重复组；检测非英文不自动翻译。仅缺失译文时写入，检查源绑定/原词/当前修订的事务一致性，防止在途结果覆盖手工/来源/AI 译文。
- [x] 持久化选中待办到个人目录，逐首原子保存状态，支持暂停/继续；操作不得在启动或无明确选歌时自动翻译。主窗口当前曲目可独立于库成员使用，批量需要核对原生身份。
- [x] 记录基础机翻来源，复用共用译文开关及备份；AI/来源准备和本地任务可以升级替换机翻，但保留历史且不绕过人工译文保护。

## 3. 界面
- [x] 设置总览增加主题一致的离线机翻面板：组件状态、下载准备、当前曲目翻译、继续/暂停、进度和错误。歌曲多选菜单增加生成基础机翻。
- [x] 按页面加载订阅进度、退出卸载订阅；后台任务随应用生命周期取消；下载需联网但离线推理不依赖联网查词开关。四语文案完整。

## 4. 验证与交付
- [x] 单元测试格式、取消/迟到、原词变化、已有译文保护、英语言识别、部分失败/续做、安全解压及包校验。
- [x] 从干净工具目录准备固定组件，真实离线模式翻译原创英文歌词并核对逐组对应；记录实际 CPU/内存与没有下载/联网的证据。
- [x] 包内隔离 UI 验证单首/批量/暂停、共享开关、六应用主题和四语；执行相关回归、分发边界检查，模型/私人任务不得进入软件包。
- [x] 更新指南/许可/发布与开发记录，生成本地预览包并校验 ZIP，提交本地 Git，报告 SHA、实测和范围限制，不推送 GitHub。


## 已完成的实现与验证（2026-11-17）

- 16 个固定组件，合计约 118.2 MB；环境清单版本 `argos-1.11.0-ct2-4.6.0-py312-win64-v2`。组件/模型不随软件分发。准备入口支持强制重新校验/重建，完成后运行固定原创句子自检；使用 Python embedded 与 NumPy wheel 原样携带的微软签名运行库，不安装系统 Python/运行库。
- 已完成单首/批量、可持久化暂停/续做、原词/成员事务复核、手工/来源/AI 保护和机翻升级历史；同步覆盖统计并合并后台刷新，四语与全部六主题保持一致。
- Core 157、Infrastructure 490 项通过（含新增离线工作流 33 项）；分发检查 2 个软件样例、73 类私人/模型档案拒绝案例通过。真实 CPU int8 测试只使用原创歌词：最终一次 3 组 2.41 秒、子进程峰值约 149.9 MiB、CPU 1.36 秒；空白/重复组、网络入口阻止、取消与释放租约通过。
- 首次干净下载与校验已实际执行，随后固定版本重建和真实推理通过。初版依赖试跑暴露 setuptools 新版移除 pkg_resources，最终固定 80.9.0；不包含完整高层分句链，因此维护时不得擅自改为自动解析全部依赖。
- 包内 UI 使用独立个人目录和固定引擎夹具，真实模型另由基础设施工作流验证；不操作真实 Apple Music 或用户歌词。不声称已覆盖全新机器、全部 CPU/DPI/显示器，也未使用系统防火墙做全机断网验收。英文短句和同形词识别存在歧义，首版不提供其他语言/自动转译。
