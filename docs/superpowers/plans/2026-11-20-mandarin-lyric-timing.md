# 打轴前检查与普通话歌声对齐

**目标** 在采集录音前确认模型可编码原词，并在制作动态歌词窗口提供可按需准备的普通话离线对齐。

**实现** 继续使用现有 PCM 输入和逐行校对编辑器。覆盖检查与对齐使用同一模型的字符或音素编码，返回可处理行数。普通话组件与已装多语言组件分别准备，模型资源在本机工具目录通过固定版本和 SHA-256 校验。原文、行序和重复句保持可编辑，音频及模型张量只在本机处理。

**依据** [离线打轴规格](../specs/2026-11-19-offline-lyric-timing.md)、[SOFA 普通话预训练模型](https://github.com/qiuqiao/SOFA/releases/tag/v1.0.1)、[SOFA 推理代码与许可](https://github.com/qiuqiao/SOFA/tree/v1.0.3)。

## 采样前检查

- [x] 给 `IOfflineLyricTiming` 增加 `CheckCoverageAsync(string[], CancellationToken)`。复用实际推理的编码函数，用相同规则处理简繁字符、重复行、标点和空白。
- [x] 在 `LyricTimingWindow.Auto.cs` 先解析和核对当前原词，再执行覆盖检查，然后才打开 WAV 或启动 Apple Music 采样。提示可识别行数和未覆盖的行号，允许更换模型或编辑原词后重试。检查、采样、推理共用取消机制。
- [x] WPF 验证覆盖不足会阻止采样回调与 WAV 选择窗口。切换普通话模型可进入草稿并继续手动校对。

## 普通话模型验证与接入

- [x] 从正式发布核对 SOFA 普通话模型、字典、运行依赖和许可证。已装多语言模型可编码《冒险岛》4/16 行，SOFA 可编码 16/16 行。对匹配同版发行的 301.11 秒录音，SOFA 保留 0/16 行建议。独立普通话清唱测试另检查了重复行和间隔，具体结果在开发记录。
- [x] 普通话组件复用已锁定的离线安装与工作进程边界。选择模型后显示该组件的准备状态，适配四种界面语言。把模型对应的音素分段回填原句，低把握时间保持留空。保存时记录运行的模型及版本，核对原绑定和歌曲身份。
- [x] 运行现有手动与自动打轴用例，检查旧安装、取消、下载校验、录音未开始时的覆盖提示、长间奏和重复原文回读。用 bundled SDK 生成预览包。验证、分发边界和待实际播放确认的项目见[本地开发记录](../../development-log.md)。
