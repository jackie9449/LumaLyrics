# Release 1.1.0 Implementation Plan

> Execute inline under the owner's explicit request to publish the current application to GitHub. Preserve existing releases and personal data; do not rewrite tags or remote history.

**Goal:** Publish current LumaLyrics as stable v1.1.0 with a verified Windows x64 installer, portable ZIP and SHA-256 files.

**Architecture:** Use Directory.Build.props as the version source and existing publish/installer scripts. Validate an isolated self-contained payload before committing, tagging and publishing assets. Create a draft only after local validation, upload all assets, then publish and read back the tag, assets and latest release.

**Tech Stack:** Bundled .NET SDK, WPF verification, Inno Setup, Git and GitHub REST API. Release/upload capabilities are absent from the available GitHub connector; authenticated API fallback uses existing Git credentials without saving or logging secrets.
