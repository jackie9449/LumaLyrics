# Argos 多语言基础机翻需求

2026-11-17，用户要求在英译中基础上继续适配法、德、西、日、韩语。

- 六种原词语言均输出中文，沿用缺词兜底；不变更原词、时间轴、空白、偏移、人工/来源/agent 保护与升级历史。
- 官方当前仅提供英→中直接包，另五种语言提供 →英语包；明确采用英语中转，记录来源路径，不把它标为直接翻译或人工校对。
- 自动识别处理多种语言的批量歌曲；提供明确的原词语言选择，用于短句/同形词纠正。选择立即保存；入队保存该选择，暂停重启不改变任务的选择。
- 准备按钮按所选原词语言显式准备固定模型；自动识别选择准备全部六条路径；复用已安装英文环境与之前校验过的基础下载，模型不进入软件/Git/个人备份。推理无下载、无云端接口，不同时加载所有模型。
- 检测到不支持语言/无法识别/超长分组/异常模型输出时明确失败；不偷偷当英文翻译。人工指定不能绕过明显不兼容的文字脚本。
- 四种界面语言及六个主题一致，保留中断/取消、任务逐首持久化及备份；使用原创夹具真实验证每个新增方向。
- 本地开发与提交，不操作真实播放/用户歌词，不同步 GitHub。
