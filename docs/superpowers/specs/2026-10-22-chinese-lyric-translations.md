# Optional Chinese lyric translations

- Add a Chinese translation Settings page. Main-window and floating lyric visibility are independent, saved immediately, initially off. Keep the main playback page free of selectors.
- Render a smaller Chinese line below its original lyric, on the existing original timeline and offsets. Never replace the next original lyric with a translation. Empty intervals and confirmed instrumentals remain blank. Toggling must work immediately and offline.
- Store translations in a separate personal `translations.db`, tied to exact original text by SHA-256 and conservative recording identity. Preserve original/manual lyrics. Export readable translation JSON and consistent snapshots; restore into a new personal directory. Software archives must exclude all private translations and reports.
- Use public metadata and lyric endpoints without credentials, encrypted endpoints or audio access. Match title, complete artist credits, recording version and duration, then align complete original lyric sequences before accepting a community translation. Preserve provider attribution, URL, preparation time, coverage and the fact that semantic accuracy has not been manually confirmed. Reject missing/ambiguous/partial/malformed mappings; do not invent timings or translate names/credits as lyric text.
- Batch preparation covers the whole active native library, prioritizing foreign lyrics already available. Confirm language from lyric content where available; titles alone cannot prove language. Classify unavailable originals, absent translations, network failures and version conflicts separately, resumably and visibly. Do not call a missing lyric instrumental or claim every translation is correct. No AI drafts without the user's choice to allow them.
- Cancellation, offline preference, concurrent workers, source changes and track changes must not show stale translations or lose existing data. Back off on service errors and respect response limits.
- Verify source and packaged WPF behavior with self-authored bilingual fixtures, unit tests for alignment/matching/storage/export, and distribution privacy checks. Actual personal batch results stay in the personal directory, with aggregate coverage reported honestly.
