# 原词长尾段、拒用诊断及旧失败重评需求

- 最后一句不足全曲55%只作风险信号。仍拒绝版本/艺人/时长不符、越界、损坏、正文缺失；只有与来源全文顺序规范化一致、文字量及时间展开足够的候选可通过长尾段例外，不推断音频器乐或语义已审核，不修改时间轴。
- 自动候选、播放、批量及手动弹窗共用判定原因。逐首保留/显示无结果、来源不可用、歌曲信息不符、时间轴/正文失败。界面将置信度改为歌曲信息匹配度，并分开显示自动检查结果。
- 策略升级使旧六小时负缓存失效；只将相关未完成原词重新排队，保留人工/现有可靠绑定、时间偏移及译文/任务。当前规则下的新失败仍有效；兼容旧两列失败表以及旧程序后写记录，读模式不做迁移。
- 用户已授权重评当前个人库相关失败。完成隔离测试后先作个人数据库一致快照，再重放已有候选、查询仍缺失的相关成员；遇到来源错误保留具体原因，不冒充全部成功。不触发播放/切歌，不开启全库自动预缓存或修改联网/暂停偏好。
- 四语六主题，遵循本地Git/开发记录；私人响应、快照、重评报告仅在软件外个人目录。
