# 悬浮歌词译文与材质控制 · 0.10.1

1. 按用户要求移除主窗口、悬浮歌词和设置中的“待校对”标志。个人译文的来源、AI 属性、原词哈希和原始校对记录仍保存在个人数据中，不把隐藏标志当作人工校对。
2. 在悬浮歌词上方的悬停工具栏加入“中文译文”开关，只控制悬浮歌词，即时保存，并与设置中的悬浮开关双向同步。保留主窗口开关、拖动、锁定穿透与纯音乐留白。
3. 圆角改为 0–100% 比例，0% 为直角，100% 为短边一半的圆角半径。按实际布局尺寸计算；文字换行、译文显隐、宽度和 DPI 改变后，WPF 蒙版、材质及原生玻璃背景使用相同的圆角。迁移旧像素值，保留各主题的独立保存、取消、重置行为。
4. 背景不透明度提供 0.1% 的调整步长；在 0–10% 范围内将模糊、反光、纹理和边框由零平滑渐入。文字透明度独立，0% 不保留背景效果，10% 及以上保留原有材质观感。
5. 仅修改软件代码和原创验证素材，不重新准备个人译稿或恢复已暂停的批量查询。通过单元测试、隔离 WPF 检查、分发检查后生成运行包，并按既有授权同步 GitHub；不得覆盖更新的远程提交。
