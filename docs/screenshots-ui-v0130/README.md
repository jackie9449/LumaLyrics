# 0.13.0 右侧播放列表与慢响应验证

新增 10 项媒体确认测试覆盖读取超过短超时后继续等待、保留同一个未完成读取、临时超时重试、录音/播放器/新鲜度/播放状态校验、真实总时限及取消后的迟到成功隔离。单元测试总计 231 项（Core 49、Infrastructure 182），全部通过；Release 构建无警告，分发边界继续拒绝 26 类个人文件或模型。

新增 WPF 专项覆盖右侧队列的真实顺序与重复项、虚拟化、个人样式封面、刷新、旧读取丢弃、导航、空/部分/失败列表、封面索引失败、三种主题、窗口最小化和退出取消。原生就绪检查使用原创无障碍窗口，故意让本地筛选延迟 1.8 秒出现；另用本应用测试窗口验证过期、失败及成功操作的最小化归属。公开界面均为原创文字与几何封面。

源码与自包含运行包分别通过全量 552 项 WPF 检查，包含新增 42 项与上一版 510 项回归。运行包通过随附 Microsoft host 启动，使用独立数据目录。歌曲操作按钮也在文字就绪之后继续延迟 1.2 秒出现，验证不会把元数据可见当作整个操作已经可用。队列行在 1220/980/820 宽度都受滚动视口约束，时长和右侧边缘不会被裁剪。
