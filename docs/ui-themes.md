## 封面与色彩

两种玻璃主题会直接从当前显示的封面取色。暖色封面对应深琥珀或浅米杏背景，冷色封面对应深蓝灰或浅蓝灰背景，背景光晕、面板高光、按钮和滚动条也会协调变化。黑白封面使用中性灰。缺失、损坏、完全透明的封面会恢复所选主题的默认配色，不沿用上一首的颜色。

取色在本机将已解码封面缩小到最多 64 × 64 像素，按可见像素提取主色和有足够占比的辅助色，降低黑白边框及小噪点的影响。主题分别限制深色与浅色表面的明度、饱和度，保持正文和控件可读。不会额外下载图片、保存派生封面或修改个人缓存。

切歌后的配色以 650 毫秒柔和过渡；连续切歌从当前可见颜色继续，结束后释放动画时钟。设置「常规 → 减少界面动画」和 Windows 界面动画偏好均会生效。切换明暗主题立即应用，避免跨明暗过渡中出现文字难读的帧。切到谷歌平面时保留固定丁香色，返回玻璃主题时使用当前封面配色。

左侧提供当前歌词和音乐库，底部为设置和诊断。四个入口使用矢量图标，图标保持清晰居中，背景层提供连续的悬停、按压、选中和键盘焦点反馈。[当前导航预览](screenshots-ui-v0166/README.md)。顶部「桌面歌词」控制悬浮窗，缓存进度快捷入口打开「设置 → 资料库」；底部保留校准、导入、更换歌词和重新搜索。窗口缩小时转为上下布局，进度与播放控制仍可使用。

设置提供「应用界面」「悬浮歌词」「常规」「个人资料」「中文译文」「资料库」六个分类。「悬浮歌词」页直接显示完整外观编辑器；托盘及悬浮工具栏的外观快捷入口统一跳转到该页。背景、按钮、标签、字体菜单和滑块共享应用主题，文字与排版／背景与布局使用横向页签。只有预览、实际悬浮窗及其工具栏使用独立外观；切换悬浮主题不会改变设置界面。八种悬浮主题、字体、配色、透明度和保存 / 取消继续可用。

「资料库」页直接显示歌词与封面进度、只读来源路径，以及选择资料库、暂停、继续、重试操作。缓存快捷入口复用已打开的设置窗口；离开页面和关闭设置会释放进度订阅，后台准备仍按原有偏好运行。

应用主题选择后立即保存；悬浮外观在设置内独立保存或取消，离开该分类或关闭设置还原未保存调整；常规表单修改后点击「保存常规设置」。三类操作分别生效。

主窗口的玻璃效果通过应用内的半透明表面、高光和背景光晕实现。悬浮窗采用相同的分层材质风格。Windows Accent 系统模糊会忽略透明 HWND 的圆角区域与 WPF 透明蒙版，产生四角外溢；0.6.1 在圆角大于 0 时自动使用半透明材质，保留不透明度、高光、边框与平滑圆角。外观面板显示“圆角玻璃材质 · 已避免系统模糊溢出”。圆角为 0 时仍可请求原生模糊，系统不支持时同样回退；模糊开关偏好保留，完全透明与纯音乐仍关闭系统模糊。没有实现真实光学折射。

0.6.1 在本机 150% DPI 下，用原创棋盘背景实际合成两种悬浮窗；原版四角背景最大通道偏差为 98，修复后为 0，直角模糊切回圆角也为 0。另检查原生窗口区域、WPF 四角透明、锁定/解锁、隐藏/显示、宽度/字号及纯音乐状态。实图：[液态玻璃](screenshots-ui-v061/overlay-liquid-native.png)、[雾面毛玻璃](screenshots-ui-v061/overlay-frost-native.png)。

## 运行

解压完整运行包后双击 Launch.vbs，或使用 LumaLyrics.exe。运行包自带 .NET 运行时；Launch.vbs 使用随包 Microsoft host，不需要安装 SDK。原本的数据目录保持为 %LocalAppData%/LumaLyrics；新 UiTheme 字段默认液态玻璃，旧外观参数继续保留。

## 构建与验证

Windows x64，SDK 10.0.402。scripts/common.ps1 优先使用仓库内 .tools/dotnet。

```powershell
./scripts/build.ps1
./scripts/test.ps1
./scripts/publish-ui.ps1
```

```powershell
./.tools/dotnet/dotnet.exe exec ./src/LumaLyrics.App/bin/Release/net10.0-windows10.0.19041.0/LumaLyrics.dll --data-dir ./.tools/qa-ui-v051 --verify-ui ./.tools/qa-ui-v051-captures --exit-after-capture
```
