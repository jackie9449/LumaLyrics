# 大窗口歌词宽度验证 · 2026-11-08

歌词面板原先包含固定 MaxWidth=820 的内部网格。窗口放大或隐藏队列后，外层面板继续扩展，正文却保持窄列居中，造成额外的左右空白。修复移除这一层上限，保留现有页面宽度边界、18–44 DIP 响应式内边距、字号、封面和队列布局。原词及中文译文共用同一个有限滚动视口，长句按实际宽度换行。

修改前，新增的面板利用率检查在六主题下复现，响应式及设置专项为 337/355；18 项失败集中于宽窗口内容受限。没有把旧的 820 上限继续当作正确结果。

增强 --verify-responsive-layout 覆盖六主题、820/980/1220/1440/1920/2560 尺寸、宽而矮窗口、播放列表显示与隐藏、真实最大化及还原。检查内容与面板的边距范围、有限视口、长英文与中文同宽且可换行、方形封面和播放控件的边界、连续缩放及手动浏览状态；保存原创双语样例的宽窄窗口截图。

Release 构建零警告、零错误；460 项单元测试通过。源码增强响应式及设置专项 427/427；最终预览包同项 427/427、中文显示 55/55、播放侧栏 100/100，共 582 项布尔检查全部通过。已查看宽屏、原生最大化及窄窗双语截图；分发检查通过 2 个软件样例与 69 类私人文件拒绝案例，最终 ZIP 与输出目录逐文件散列一致。

通过 scripts/common.ps1 选择 SDK，使用程序目录外新建 --data-dir 运行 --verify-ui <report> --verify-responsive-layout --exit-after-capture。其它回归为 --verify-translations 和 --verify-playback-sidebar。检查 ui-check.json 的布尔结果及截图。现场报告、截图和数据目录保留在个人 QA 位置，不进 Git。

独立预览使用 scripts/publish-ui.ps1 -PreviewLabel wide-lyrics 生成，并核对分发隐私边界、ZIP 文件集合及 SHA-256。验证不连接真实 Apple Music，也不修改个人歌词、偏移或原词／译文对应关系。
