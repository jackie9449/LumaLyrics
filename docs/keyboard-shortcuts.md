# 全局快捷键

软件窗口内可直接按 **空格** 播放／暂停，长按只触发一次。输入文字、录入快捷键，或焦点位于按钮、选择器、进度条等控件时，保留该控件原有的空格操作。普通空格只在软件内响应；切换到其他软件后，使用下面的全局组合。

打开「设置 → 快捷键」。软件在后台、最小化或隐藏到托盘时也可使用；退出软件后释放所有组合键。默认组合如下，已有的显示／隐藏与解锁自定义设置会保留。

| 操作 | 默认组合 |
| --- | --- |
| 播放／暂停 | Ctrl + Alt + Space |
| 上一曲 | Ctrl + Alt + ← |
| 下一曲 | Ctrl + Alt + → |
| 歌词提前 0.1 秒 | Ctrl + Alt + ↑ |
| 歌词延后 0.1 秒 | Ctrl + Alt + ↓ |
| 重置当前歌曲偏移 | Ctrl + Alt + R |
| 显示／隐藏悬浮歌词 | Ctrl + Alt + L |
| 解锁悬浮歌词 | Ctrl + Alt + U |

歌词校准改变当前歌曲的个人偏移，保留原始时间戳；没有可用歌词绑定时不会修改其他歌曲或全局偏移。长按不会重复触发。播放控制使用当前媒体会话，不要求 Apple Music 位于前台。

点击组合键输入框后按下新的组合。使用 Ctrl 或 Alt 搭配字母、数字、方向键等；Backspace 或 Delete 清空以停用，Esc 撤销本次录入，Tab 切到下一项。Windows 保留组合和无修饰的普通按键不可分配。录入时不会同时执行该操作。

点击「保存快捷键」后立即生效。页面会标出格式错误、重复组合及被占用的组合。「自动解决冲突」保持可用项目和已停用项目，优先添加 Shift，再从 Ctrl + Alt + Shift + F1–F11 中寻找空闲组合；查看分配结果后保存。自动分配本身不改写设置。如果其他程序在检查与保存之间抢先注册，保存会重新检查，失败时恢复原有注册；无法恢复的项目会明确标出。

Windows 不可靠地提供占用者名称，应用不会假称某个程序占用了按键，也不会抢占其他软件的注册。若偏好原组合，可关闭旧版浮光歌词，或在另一个使用相同组合的软件中改键，然后再次保存。启动时单个冲突不会阻止其他可用快捷键，并会显示托盘提示。系统底层键盘钩子可能不出现在 Windows 注册冲突检查中，此时可手动换组合。

快捷键文案随四种界面语言切换，组合键使用统一写法。个人设置记录在个人数据目录，不进入软件分发包。
