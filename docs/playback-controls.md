# 播放进度与滑条

播放页的进度条支持点击位置、按住拖动。拖动时显示目标时间，松开后提交一次跳转；Esc、失去鼠标捕获、窗口隐藏或歌曲变化会取消未提交的操作。键盘方向键每次调整 5 秒，Page Up / Down 调整 10 秒，Home / End 到两端，松开按键提交。歌曲总时长未知、没有播放会话或没有支持的跳转接口时禁用。

优先使用系统媒体会话的进度控制。Apple Music 没开放系统能力时，检查其原生 `LCDScrubber` 的可写 RangeValue、秒制范围与当前录音时长；执行前再次核对媒体会话、原生歌名、歌手和专辑。只操作该控件，不发送播放、下一首、鼠标或键盘命令，不激活或恢复 Apple Music 窗口。选曲、队列选择与跳转共用最新请求取消。

提交后读取真实媒体时间轴，确认新位置才显示已跳转；失败、超时或切歌后恢复跟随实际播放。拖动预览不改变歌词时钟。本机 Apple Music 播放状态下前跳和回跳已获得实际时间轴确认。暂停时原生进度可能已经改变，而系统媒体时间轴延迟到恢复播放才更新：此时显示未确认提示，保持实际歌词位置，不自动播放或重复跳转。

主应用所有滑条、包括外观编辑器的设置项，使用统一的轨道加厚、滑块放大、按压中心和键盘焦点反馈；保留各主题的颜色。后台任务进度条平滑改变填充，忙碌条按自身宽度移动。开启“减少界面动画”或系统关闭动画时立即更新，隐藏或卸载时停止并释放动画。实际悬浮歌词、工具栏和预览保持各自的独立外观。

隔离验证：使用 `scripts/common.ps1` 选取 SDK，运行完整单元测试。界面验证参数为 `--data-dir <仓库外独立目录> --verify-ui <仓库外报告目录> --verify-seek-sliders --exit-after-capture`。仅显式 `--verify-native-library-playback` 模式可执行实机验证，现场报告包含私人录音信息，禁止进入 Git 或软件包。
