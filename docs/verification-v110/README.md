# 1.1.0 发布验证 · 2026-11-08

本次发布当前源码，版本集中更新为 1.1.0，README 下载入口与正式资产同步。功能包括资料库与歌词管理、批量本地 agent 翻译、原词搜索改进、歌单及进度控制，保留已经撤销乐器识别后的状态。

## 发布与数据边界

scripts/publish.ps1 生成自包含便携版；scripts/publish-installer.ps1 从同一文件目录生成安装器。软件文件、说明文档及第三方许可可分发；个人数据库、缓存、歌词、翻译、任务、媒体与模型不能进入资产。验证使用软件目录外新建 --data-dir，不连接真实媒体或网络歌词服务。

发布资产为 LumaLyrics-1.1.0-portable-win-x64.zip、LumaLyrics-1.1.0-setup-win-x64.exe、各自 .sha256 及 SHA256SUMS.txt。版本标签为 v1.1.0，正式发布为非预发布，保留既有 v1.0.0 和其它草稿。

## 首轮发现与修正

首轮完整 WPF 回归为 1698/1707，9 项未通过：

- 合并后的显示页确实缺少原词校对入口，已补回并复用既有打开逻辑；不自动捕获原生内容。
- 六主题管理页检查仍要求旧页面恰好四个按钮。现在核对当前必要命令，同时保留窗口归属、无第二管理窗口和可见时订阅的原断言。
- 1220 宽度队列边界的差值为 2.2737367544323206e-13 DIP。几何检查增加 0.000001 DIP 数值精度容差，视口高度和边界条件保留。
- 悬浮居中检查将 PointToScreen 的物理像素与 ActualWidth 的 DIP 相加，150% 缩放下单位不一致。改为比较两个控件经 PointToScreen 转换的中心，维持原有小于 2 像素的误差条件。

一次工作区验证在任务目录已生成后过早读取尚未展示的异步批次列表，导致缺少最终报告。Loaded 已经拥有合并读取时，Reload 只排队下一轮；验证现等待实际可交接批次出现，最多 5 秒，保留原有数量、分块和复制结果检查。没有改变生产读取或放宽任务校验。

## 既有兼容性限制

界面验证不证明真实 Apple Music 的播放／歌单续播／模式切换成功，相关现场确认限制保留在歌单和播放专项记录中。外部 agent 翻译的语义仍由用户核对，不把来源对齐或结果通过结构校验称为人工审核。不同客户端版本、DPI、系统原生玻璃及长时间运行仍需相应环境验收。

1.0.0 完整回归曾存在动画时刻、焦点和玻璃淡出检查未通过，详见历史验证记录；本次完整回归的实际结果另行记录，不将未重跑或未通过项记为通过。程序与安装包未进行代码签名。
