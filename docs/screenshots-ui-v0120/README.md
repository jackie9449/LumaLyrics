# 0.12.0 播放列表与插播验证

221 项单元测试通过（Core 49、Infrastructure 172）。播放列表专项的 35 项实际 WPF 检查全部通过，覆盖独立当前录音、原生顺序与重复项、封面、虚拟化、浏览状态保留、插播序列化、键盘与双击意图、异常、空队列、部分列表、过期读取、退出取消、三种主题及 1220/980/820 宽度。
