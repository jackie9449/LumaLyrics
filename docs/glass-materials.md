# 玻璃材质与实时外观编辑 · 0.16.1

本次重制参考 Apple 官方的 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 与 WWDC25 [Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)。液态玻璃强调随形高光、透镜般的厚度感、环境融合及清晰的内容层次；传统毛玻璃侧重散射与柔和扩散。材质应随交互轻微响应，并兼顾文字可读性、透明效果与减少动画偏好。

## 两种悬浮材质

- **液态玻璃**：实时柔化背后的窗口内容，同时透出更多细节；使用中性薄底、柔和的弧面高光、内外边缘和暗部反光建立厚度。指针移动时高光轻微跟随；减少动画或关闭动效时固定光源。新预设默认启用文字明暗适应，浅背景用深色字、深背景用浅色字，并用不同切换阈值避免闪烁。
- **雾面毛玻璃**：更充分的背景扩散、温润浅雾面、安静的边缘反光与细微颗粒，配合深色文字。与液态玻璃的清透感区分，不使用紫色光斑或厚亮框。

两种材质在 Windows 上以独立的 Windows Composition 背景层配合清晰的 WPF 文字层实现。背景层拥有圆角几何裁切，始终位于歌词下方、不会激活或拦截点击；移动、缩放、DPI、隐藏、暂停淡出和纯音乐状态与歌词同步。系统背景柔化不可用或系统关闭透明效果时保留半透明回退。Windows 11 使用官方 `DWMWA_USE_HOSTBACKDROPBRUSH`，旧版本保留兼容路径。

这是针对 Windows 的原创实现，参考 Apple 的设计原则；没有调用 Apple 的专有渲染器，也没有完整复现其物理折射、形变及平台动态系统。预览场景与文档壁纸均为原创矢量绘制，不包含 Apple 素材或个人封面。

0.16.1 修复玻璃背景偶发变黑：原生背景窗口使用 `WS_EX_NOREDIRECTIONBITMAP`，分层窗口的原生 alpha 固定为 255，以保留点击穿透；背景强度与窗口淡出都交由合成视觉层的浮点透明度处理。背景层与歌词窗口共享同一个 owner，避免隐藏后再显示时被 owner 遮住。[连续画面、淡出、焦点及命中测试记录](screenshots-ui-v0161/README.md)。

## 调整与字体预览

进入「设置 → 悬浮歌词 → 打开悬浮歌词独立外观」，或使用悬浮工具栏 / 托盘的外观入口。

「背景与布局 → 圆角比例」以百分比设置：0% 为直角，50% 的半径等于短边四分之一，100% 等于短边一半。圆角随换行、中文译文和窗口高度共同缩放，WPF 文字蒙版、材质轮廓及原生背景裁切使用同一比例。旧版像素圆角按旧字号、留白与单双行的基准高度换算，继续保留各主题的自定义和保存/取消逻辑。

背景不透明度可按 0.1% 微调。底色使用所选不透明度，玻璃模糊、高光、颗粒及边框在 0–10% 区间平滑渐入；0% 完全清除背景，10% 及以上沿用原有材质强度。该控制不降低文字不透明度。预览与桌面悬浮窗采用同一计算，仍支持系统透明效果关闭时的回退。

- 设置与外观面板均可并行操作。编辑时临时显示并允许拖动悬浮歌词；关闭面板后恢复先前的锁定/显示状态，保留主动调整的位置。
- 字体列表展示每种已安装字体的名称和「浮光歌词 · Aa Bb 123」字样。移动指针即可同时预览桌面歌词与面板中的字体；移开或关闭列表恢复选定字体，点击才选定。
- 悬停预览不修改选定字体或个人设置，其他界面的保存操作也不会写入悬停字体。保存外观只采用选定项；取消恢复打开面板前的外观。
- 字体列表按需生成可见项，支持滚动和键盘选择；中文缺字采用本机字体回退，不下载或捆绑字体文件。
- 液态玻璃的「文字随背景明暗调整」可关闭。手动选择文字颜色时会关闭该选项，尊重指定颜色。面板使用原创背景进行预览；实际环境以桌面悬浮窗为准。

现有自定义外观会保留。0.7.1 起，每个主题分别记住自定义样式，切走再切回即可恢复；「保存外观」保存本次所有主题的调整，重启后保留，取消撤销本次全部调整。要重新使用默认材质，请点击「重置当前主题」；其他主题不受影响，当前字体和主要排版偏好继续保留。[主题记忆与重置说明](theme-memory.md)。

## 隐私与验证

运行时的系统玻璃由 Windows 合成器处理，不截取或保存桌面图像。可选的文字明暗适应只在窗口外缘读取少量色点用于即时计算，不提取文字，不保存或上传色点。个人歌词、封面、绑定及数据库始终保存在独立资料目录，不进入软件包或 GitHub。

验证使用隔离数据目录、原创歌词与不透明的原创测试场景。既检查圆角外的像素不变，也检查圆角内的细节被柔化且保留背景颜色，防止把黑块或纯色底误认为模糊。另验证字体悬停/移开/选择/保存/取消、编辑时拖动、锁定与隐藏恢复，以及关闭后无残留背景窗口。原有主界面封面取色、独立浮窗样式、个人文件导出/恢复、纯音乐留白与歌词行为继续回归。
