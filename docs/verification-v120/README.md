当前任务明确授权推送并发布 v1.2.0；常规开发仍遵守本地 Git 规则。原 v1.0.0 和 v1.1.0 标签及资产保留。

## 验证方法

使用 scripts/common.ps1 选择 SDK 10.0.402、已核对的离线 NuGet 包和独立缓存，锁定恢复、Release 构建和单元测试。离线恢复关闭该次在线 NuGet 审计，不代表执行过最新漏洞审计。

运行包以软件目录外全新 --data-dir 执行 --verify-ui，检查布尔结果与截图。选择空格控制、交互更新、本地化、悬浮、译文和完整回归；隔离模式不控制真实 Apple Music。安装检查只在无已安装产品及同名开始菜单目录时运行，保存并恢复原桌面快捷方式，验证安装、版本、文件、启动、重复安装、卸载和外部个人样例保留。

首轮构建零警告、零错误，558 项单元测试通过（Core 134、Infrastructure 424），运行包空格 19、交互 66、本地化 111、悬浮及外观档案 101、译文／简繁 145 项专项通过。

## 既有现场限制

Apple Music 暂停时可能延迟或回退进度；程序保留未确认提示，不自动播放或重复提交。歌单／队列、四种语言的真实客户端账户、多屏跨 DPI 和不同系统的玻璃效果尚未逐项复验。本地化与 UIA 样例不证明真实播放成功。源歌词时间戳准确性和中文译文语义也不因程序测试通过获得保证。

原始报告、截图和测试数据保留在软件外个人 QA 目录。程序与安装器未作应用代码签名；SHA-256 用于文件完整性核对。发布使用既有、签名有效的 Inno Setup 6.7.3 编译器。
