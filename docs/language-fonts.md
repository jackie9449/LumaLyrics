# 按语言设置悬浮歌词字体

在 **设置 → 悬浮歌词 → 文字与排版** 中设置。

1. 第一行从 Windows 用户系统语言初始化，保留升级前的字体。它独立于软件界面语言。
2. 点击字体行下方的 **＋**，选择需要单独设置的语言，再选择字体。可以连续添加；同一种语言只保留一行。额外的行可用 **−** 移除。
3. 字体下拉列表提供对应语言的真实字体样张。悬停只临时预览，点击才选定；关闭列表或移开恢复选择。预览区切换到该语言的示例文字。
4. **保存外观**保存本次修改的各个主题；**取消**或离开撤销本次草稿。字体仍随悬浮主题独立记忆。

支持 30 种语言：简体中文、繁体中文、英文、日文、法文、西班牙文、德文、韩文、意大利文、葡萄牙文、荷兰文、瑞典文、丹麦文、挪威文、芬兰文、波兰文、捷克文、土耳其文、越南文、印度尼西亚文、马来文、俄文、乌克兰文、希腊文、阿拉伯文、希伯来文、印地文、泰文、孟加拉文、泰米尔文。

## 字体列表与离线覆盖

列表按字体本身的字形覆盖筛选，不以 Windows 自动替补出的字形作为支持证据。中文楷体、黑体等中日韩字体不会因为含有 ABC 就出现在英文、法文等西文字体列表。英法德等共享拉丁文字的字体可以同时出现在多个语言列表，重音字母覆盖不足的字体会被过滤。CJK 地区版本分别归入对应语言。

随程序附带 SIL OFL 许可的 Noto 字体，提供以上语言的常用字符和组合排版。它们仅供程序使用，不修改系统字体。实际显示按字符范围分配字体，未覆盖的生僻字和符号继续使用 Windows 字体回退。这里不承诺所有历史文字、罕见 Unicode 字符或所有 emoji 均包含在内置字库中。

换电脑后，如果原字体未安装或不适合所选语言，保留原选择并显示提示，暂用该语言内置字体。重新安装字体后重启程序，或改选列表中的字体。个人备份会带上字体选择，系统字体本身不写入个人备份。

## 显示与识别

本次设置作用于悬浮歌词及其预览。原词、下一句、中文译文各自选择字体；中、日、韩混排按文字范围分配。中文译文按实际简繁显示选择字体，不能被误认为日文。阿拉伯文与希伯来文保留从右向左排版。软件主页面的主题字体不受影响。

英、法、西、德等共享字母的语言使用 Windows 离线 ELS 识别；没有联网翻译或上传。短句、人名、同形词和纯汉字日文可能有歧义；不能保证逐句识别完全正确。无法识别时使用默认语言/相应文字系统的内置字体。预览示例按所选行强制使用该语言，方便准确比较字体。

字体设置只改变显示，不修改原词、译文、SHA-256、时间戳、手动绑定、简繁转换结果或歌词偏移。

## 开发验证

通过 `scripts/common.ps1` 选取 SDK。使用软件目录之外的独立 `--data-dir`，运行 `--verify-ui <报告目录> --verify-language-fonts --exit-after-capture`。该检查验证全部语言的字形覆盖及原始字体文件、分类、实际 WPF 混排字形来源、增删、悬停与保存取消，并生成宽窄窗口和多文字样张。不要使用真实资料目录运行验证。
