# 个人资料与软件分开保存 · 0.10.0

软件 ZIP 只包含程序、运行时、文档和原创界面示例。个人歌词、中文译文、封面、绑定、校准与设置保存在程序目录之外，更新软件会继续读取原来的个人数据。

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| `LumaLyrics-0.10.0-ui-preview-win-x64.zip` | 程序与运行时 | 可单独分发、替换和更新 |
| 个人文件夹 | 可读取的歌词、原始封面、清单和恢复快照 | 自己保存、查看和备份 |
| `*.lumalibrary.zip` | 个人文件夹的独立 ZIP | 自己备份、换机和恢复 |

## 当前数据与导出

现有数据默认仍在 `%LocalAppData%\LumaLyrics`。不移动、删除或重建旧库，导入任务与手动校对记录保留。打开「设置 → 个人资料」可查看和打开当前目录。

点击「导出个人文件夹」，选择程序目录之外的保存位置。应用创建一个新的、带时间的子目录。也可直接选择「导出个人备份 ZIP」，保存为独立的 `.lumalibrary.zip`。已有文件与目录不会被覆盖。

导出期间使用数据库在线快照，包含已经提交的 WAL 数据，不需要停止原有导入任务。正在继续下载的内容可以下次再次导出，得到新的快照。

个人文件夹结构：

```text
浮光歌词个人资料-时间/
  lyrics/                UTF-8 LRC，以及手动保留的 TXT
  covers/                原始 JPEG / PNG，相同图片只保存一份
  translations/          中文译文 JSON，包含原文哈希、行号、来源和校对状态
  state/                 词库、封面映射、设置与恢复信息
  personal-library.json  曲目对应、来源、偏移、尺寸和文件校验
  README.md
  .gitignore             避免个人文件意外进入 Git
```

自动歌词需通过现有的元数据、动态时间轴和全文检查，才会生成可读取的 LRC；手动锁定的 LRC/TXT 保留原文。纯音乐不生成歌词文件，缺失和待核内容不会补写文字或虚构时间轴。图片按实际尺寸记录高清状态，不重新编码、不把低清图片冒充高清。相同专辑封面可以由多个曲目引用同一图片。

`state/` 还保留历史候选与导入队列，用于恢复既有状态；这些记录不代表全部歌词已准确，也不表示已经 Apple Music 逐首核对。手动偏移和全局偏移独立保留，导出的 LRC 原文不会额外写入重复偏移。个人校对附注若存在，也会一并保留。网络响应日志、运行锁、进程记录、Apple 账号、音频和原始 Apple Music 资料库文件不进入个人备份。

0.10.0 的 `state/translations.db` 保留中文译文与准备队列。AI 译稿的待校对标记一并导出和恢复；可读译文记录在 `translations/`，不修改原词。旧的无译文备份仍可在新版恢复；含译文的备份需由 0.10.0 或更新版本读取。详见[中文译文指南](chinese-translations.md)。

## 恢复与更换存储位置

1. 在「设置 → 个人资料」选择「从文件夹恢复」或「从 ZIP 恢复」。
2. 选择保存位置，应用新建一个个人数据子目录。恢复前检查格式版本、文件路径、SHA-256 和图片尺寸；不会合并或覆盖已有目录。
3. 如需启用恢复结果，点击「下次启动使用其他资料目录」，选择刚恢复的数据目录。
4. 退出浮光歌词并重新打开。主题、悬浮外观、手动绑定、时间偏移和队列会随个人数据恢复。

当前窗口与任务不会在选择目录后立即切换；原数据保持原样。位置选择保存在机器本地的 `%LocalAppData%\LumaLyrics\data-location.json`，软件 ZIP 和个人备份均不包含这个机器位置指针。下次更新软件时仍使用所选目录。若磁盘断开或目录失效，应用提示重新选择已有资料，不会悄悄新建空库。

个人数据不能放在当前或旧版软件目录中。删除或替换软件目录时，程序之外的个人目录和独立备份会继续保留。「清理查词响应缓存」也保留所有已导入的个人歌词、封面、绑定与校准，包括自动下载的歌词。

## 命令行

自包含包内的 Microsoft host 无需安装 SDK。以下命令均在运行包目录执行；路径有空格时保留引号。恢复目标须尚不存在。

```powershell
./runtime/dotnet.exe exec ./LumaLyrics.Probe.dll --export-personal "$env:LOCALAPPDATA/LumaLyrics" "D:/个人资料/浮光歌词快照"
./runtime/dotnet.exe exec ./LumaLyrics.Probe.dll --pack-personal "D:/个人资料/浮光歌词快照" "D:/个人资料/浮光歌词快照.lumalibrary.zip"
./runtime/dotnet.exe exec ./LumaLyrics.Probe.dll --validate-personal "D:/个人资料/浮光歌词快照.lumalibrary.zip"
./runtime/dotnet.exe exec ./LumaLyrics.Probe.dll --restore-personal "D:/个人资料/浮光歌词快照.lumalibrary.zip" "D:/个人资料/恢复后的浮光数据"
./runtime/dotnet.exe exec ./LumaLyrics.Probe.dll --use-data "D:/个人资料/恢复后的浮光数据"
```

`--use-data` 仅记录下次启动位置。`Launch.vbs --data-dir "D:/个人资料/恢复后的浮光数据"` 可指定一次启动的位置；显式目录优先于机器位置指针。`Probe.cmd` 的诊断日志也写入当前个人数据目录。

## 分发与验证

`scripts/publish-ui.ps1` 在压缩前运行分发边界检查，遇到数据库、LRC/TXT、个人清单、设置、封面缓存、日志或个人 ZIP 会停止打包。文档中的界面素材均为原创验证数据。个人数据目录和导出目录自带 Git 忽略规则，个人文件不提交 GitHub。

开发验证使用独立 `--data-dir`，实际测试导出文件夹、ZIP、离线恢复、手动绑定与校准、共享和低清封面、损坏文件、路径越界、取消、版本检查以及现有主题与悬浮外观。个人资料页见 [界面实图](screenshots-ui-v060/settings-personal.png)。

0.6.0 验证：113 项单元测试、137 项 WPF 检查通过；源码和自包含包分别执行相同的界面验证。软件分发检查通过 2 个合法程序文件和 13 类个人文件的测试。随包启动器另以含中文、空格和分号的数据目录验证参数传递，运行时不需要安装 SDK。
