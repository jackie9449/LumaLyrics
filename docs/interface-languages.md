# 界面语言

浮光歌词提供简体中文、繁體中文、English 和日本語四种界面语言。

打开左下角设置图标，在第一项「应用界面」顶部选择「界面语言」。选择自动保存；从托盘菜单退出浮光歌词后重新启动，即可完整应用。旧配置继续使用简体中文。语言菜单始终以各语言的原文名称显示，方便切回。

主界面、设置、悬浮工具栏、音乐库与播放队列、导入及歌词校对、个人资料备份恢复、翻译任务、诊断和应用消息框使用所选语言。英文较长的操作按钮允许换行或自适应宽度，日文及繁体中文使用相应的系统字体回退。Windows 文件／文件夹选择器中的系统按钮仍由 Windows 的显示语言决定。

界面语言与「歌词简繁显示」分别保存。歌名、艺人、专辑、原始歌词、手动绑定、时间戳、译文和个人路径保留原值；界面语言不会改写个人文件或触发歌词重新翻译。自动生成的「未命名专辑」「未知艺人」等提示会本地化，真实元数据即使与提示同名也保持原样。

## Apple Music 语言兼容

浮光歌词的界面语言可以与 Apple Music 的语言不同。原生操作优先使用稳定的控件标识；需要读取按钮名称时，支持简体中文、繁体中文、英文和日文的明确名称，包含歌曲／专辑入口、插播、待播／记录、重复状态及空队列。

本次名称核对使用本机 Apple Music 1.1792.39682.0 的语言资源及隔离 UIA 样例。四种语言切换后的真实账户播放操作尚未逐一现场运行；Apple Music 后续版本更改控件时仍可能需要更新适配。未知控件或状态不会被当作成功操作。

## 本地维护

界面原文键及英文／日文资源位于 `src/LumaLyrics.Core/Localization`，繁体资源从同一组原文键生成后随软件内嵌。`UiText.T` 处理固定应用文案，`UiText.F` 保留格式参数，`UiText.Status` 仅在明确的应用状态边界显示已有记录。歌词、可编辑文字和歌曲元数据不经过界面翻译。

新增文案时同时补齐三种语言资源，保持占位符一致，验证 820／980／1220 宽度及六套主题。不要翻译主题持久标识、原生控件匹配字符串、机器协议或原词哈希。
