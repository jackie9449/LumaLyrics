# 悬浮歌词主题记忆 · 0.7.1

进入「设置 → 悬浮歌词 → 打开悬浮歌词独立外观」。八个主题分别记住各自的自定义样式：例如，将液态玻璃调成 37 px 圆角、29% 背景不透明度，再切换到毛玻璃调整，切回液态玻璃仍会恢复之前的设置。

| 操作 | 结果 |
| --- | --- |
| 切换主题 | 恢复该主题上次的调整，包括字体、字号、颜色、背景、透明度、圆角、排版、阴影和动画 |
| 保存外观 | 一次保存本次调整过的所有主题；重新打开或重启后继续使用 |
| 取消、Esc 或关闭面板 | 撤销本次对各个主题的调整及重置，恢复打开面板前选中的外观 |
| 重置当前主题 | 恢复当前主题的材质和配色默认值，保留字体、主字号、字重、宽度、单双行、对齐和切换动画偏好；其他主题不受影响。重置也需要保存 |

首次使用一个尚无记录的主题时，采用它的预设材质，并沿用当前字体与主要排版偏好。之后各主题分别保存自己的排版，切换时不会互相覆盖。旧版正在使用的自定义外观会作为该主题的初始记录保留。

字体悬停仍只作临时预览：点击才选定，移开恢复。未选定的悬停字体不会进入主题记录。编辑期间悬浮歌词仍可拖动，关闭面板后恢复原有锁定和显示偏好。

主题记录与原有设置一起保存在个人资料目录的 `settings.json` 中，随个人资料导出和恢复，不进入 GitHub 或软件 ZIP。更新程序时保留个人资料目录即可。

验证：126 项单元测试、236 项源码及运行包 WPF 检查通过。主题检查使用真实列表、字体/颜色/滑块控件，覆盖切换、保存重读、取消全部草稿、单独重置及直接拉伸窗口宽度；字体悬停不写入任何主题记录。[完整结果](screenshots-ui-v071/ui-check.json)。
