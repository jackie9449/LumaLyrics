# 原词获取与拒用原因

在「设置 → 资料库与歌词 → 歌曲」选择曲目，点击「准备所选原词与译文」。未采用原词的具体原因显示在每首歌曲的状态下；长内容可悬停查看全文，单选歌曲也会显示完整原因。准备结束会重新读取状态，成功后清除旧的拒用提示。

批量准备先使用本地可用原词并做一轮精确查询。通过检查的原词会在批次仍运行时显示。第一轮没采用的歌曲显示「等待补查」，第二轮再继续查其他候选、准备现有中文和导出任务。原词与中文都来自同一次网易云查询时，可复用该次结果，译文仍要通过与当前原词的对齐检查。

「更换歌词」中的「歌曲信息匹配度」只比较歌名、歌手、专辑与时长，100% 不表示歌词全文或时间轴正确。候选预览另行显示「自动检查通过」或「自动未采用」及原因；手动确认选用仍可用，选用后保持手动锁定。

## 长尾段判断

两分钟以上歌曲，最后一句早于全曲 55% 时，程序会要求额外证据。满足以下条件可以通过长尾段检查：

- 来源同时提供全文，规范化后的同步正文与来源全文内容、顺序完全一致。
- 至少六个有效歌词组、80 个规范化字符、三组不同正文，时间展开至少一分钟。
- 原有录音版本、歌手、时长、时间戳范围、格式和正文覆盖检查通过。

只有器乐段落标记的组不算正文，也不能用来延长最后一句。没有全文、正文缺失或重排、时间点过于集中的候选仍需手动确认。以上是来源文字与时间范围检查，不代表已听音核对，也不会判定尾奏一定为器乐。程序不补造时间戳，不借用另一录音的时间轴。

## 常见原因与处理

| 原因 | 含义与处理 |
| --- | --- |
| 来源未返回歌词候选 | 本次查询无结果，可稍后重试或手动搜索/导入。 |
| 来源暂不可用／部分来源暂不可用 | 查询尚不完整，稍后重试；不会将网络错误当成不存在歌词或纯音乐。 |
| 歌名、歌手、录音版本或时长不符 | 自动采用存在录音错配风险，先核对目标与候选版本。 |
| 同步歌词缺少纯文本中的较多内容 | 同步稿可能只是一部分，可更换来源或手动检查。 |
| 尾段较长且来源缺少全文对照 | 无法确认正文是否完整，保留手动确认途径。 |
| 时间戳超出歌曲时长／时间点过于集中 | 时间轴有风险，自动流程保留拒用。 |
| 当前为手动静态原词 | 手动绑定继续保留；需要动态原词时，请明确更换或导入正确时间轴。 |

## 旧失败重新评估

匹配策略版本更新后，旧版六小时失败记忆失效；相关未完成的当前库成员重新排队，已绑定的手动歌词与可靠缓存保留。保留联网、自动预缓存与暂停偏好；关闭自动预缓存的用户可在歌曲页选择相关歌曲再准备，不会擅自启动全库任务。

当前规则下的新失败仍有重试间隔；来源不可用与候选检查失败分别记录。批量准备不受播放页失败记忆阻止，可主动重试。个人库重评前应保存一致数据库快照，逐首复核当前成员；已有正文、哈希、偏移及中文译文不因重评而替换。软件包和 Git 不包含个人响应、歌词、库清单或重评报告。
