# 0.15.0 队列拖动、歌词来源与原词校对验证

280 项单元测试通过（Core 57、Infrastructure 223），Release 发布零警告、零错误。源码和自包含运行包分别完成 613 项实际 WPF 布尔检查，全部通过，检查项一致，结果见[源码检查](ui-check.json)与[运行包检查](ui-check.packaged.json)。新增 21 项覆盖队列拖动的快照和重复位置、外部拖入拒绝、异步失败/取消/关闭、禁止预先排序，以及原词校对入口、部分比较和三种主题的表格配色及列宽。原有 592 项继续回归。

实际 Apple Music 队列已经验证向前移动、拖到队尾、分别逆向恢复原顺序，并确认当前录音与暂停状态保留。原生 WinUI 队列需要具有输入所有权的拖动操作，会短暂显示 Apple Music；不代表完全后台操作。测试未遍历所有客户端版本及所有手动/自动队列混合情况。

当前机器的 Windows OCR 实际识别了 19 行可见歌词，其中 8/20 个原词组明确对应；原生文字参考取得 16 行，其中 10/20 组明确对应。重复句及相近文字不计作明确对应，两个结果均保留当前录音与播放状态。当前仅安装 `en-US`、`zh-Hans-CN` 识别组件；日、韩文需系统组件支持，原生文字参考可独立使用。OCR 不生成时间戳，不代表完整歌曲或译文语义已核实。

真实个人校对记录及截图已完成独立备份、恢复，两项操作均无警告。原始记录、歌曲信息和截图只留在个人目录；本目录的歌词与几何封面均为原创样例。
