## 复现

以程序目录外的新建 --data-dir，使用运行包内 runtime/dotnet.exe exec LumaLyrics.dll --verify-ui <report> --verify-library-workspace --exit-after-capture。其它专项为 --verify-translations 和 --verify-library-browser。检查 ui-check.json 的布尔值与截图，而非仅看退出码。

使用 scripts/publish-ui.ps1 -PreviewLabel library-workspace-design 生成运行包。软件分发检查拒绝私人数据库、任务、歌词和进度文件，并核对 ZIP 文件散列。

## 边界

没有把用户任务交给第三方 agent，未验证外部模型翻译语义；复制只产生本机提示词。Windows 剪贴板服务忙或不可用时显示错误，可稍后重试。实际 Apple Music 原生播放、队列和长时间稳定性不属于此次界面验收。
