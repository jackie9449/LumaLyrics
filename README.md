# 浮光歌词 LumaLyrics 0.13.0

Windows 桌面歌词应用。Apple Music 负责播放，浮光歌词预缓存资料库封面与动态歌词，支持独立的透明悬浮歌词窗口。

## 这次更新

- 播放/歌词页面右侧直接显示当前播放列表，包含当前歌曲、接下来播放、封面和插播标记。可刷新，点「＋」进入音乐库选歌；三种主题和 1220/980/820 宽度均保持右侧布局，宽屏封面保持正方形。
- 修复 Apple Music 稍慢就提前返回并报错的问题：等待原生筛选、曲目和专辑界面就绪；媒体读取的短超时继续等待，不重复发出播放命令。以真实、最新的 Apple Music 录音与播放状态确认结果，新请求仍可取消旧请求。
- 选曲、整张专辑或插播确认成功后，自动最小化 Apple Music，再返回浮光；旧请求和未获确认的请求不会抢焦点或最小化较新的操作。[播放页面与选曲说明](docs/music-library.md)。
- 音乐库新增「播放列表」，分开显示当前歌曲与 Apple Music 的实际待播清单，保留插播、专辑后续曲目的原生顺序和重复歌曲。列表显示封面、艺人、专辑、时长，支持刷新与可见时自动同步；返回时保留原来的专辑、搜索和滚动位置。
- 歌曲旁新增「插播」，当前歌曲继续播放，所选歌曲排到下一首。连续插播逐个执行，最近插入的排在前面；读取原生队列确认结果，按钮的双击与 Enter 不会误触立即播放。[播放列表与插播](docs/music-library.md)。
- 修复音乐库点播误把 Apple Music 全局搜索识别为本地歌曲筛选的问题。歌曲按钮、双击和 Enter 继续核对所选录音，并等待实际媒体会话确认播放。
- 专辑卡片新增圆形播放按钮，专辑详情新增「播放专辑」。通过核对过的录音进入 Apple Music 原生专辑，按原生曲序播放整张专辑；连续点选、单曲与专辑切换共用取消旧请求的机制，保留浏览位置和独立主题。[音乐库与专辑播放说明](docs/music-library.md)。
- 悬浮歌词上方工具栏新增「中文译文」开关，悬停后可直接开启或关闭，与设置页双向同步、即时保存，保持主窗口开关与应用主题独立。移除主窗口、悬浮歌词和设置中的“待校对”展示，个人文件继续保留 AI 来源及原始校对记录。
- 悬浮圆角改为 0–100% 比例，随实际窗口高度与短边变化；100% 为短边一半的圆角半径，译文、长句、缩放和 DPI 变化时三层裁切一致。旧像素设置自动迁移，各主题的自定义仍独立保存。
- 背景不透明度支持 0.1% 调整，0–10% 之间的模糊、反光、纹理与边框平滑渐入，消除从 0% 到 1% 的突然变化，歌词文字保持清晰。[玻璃材质说明](docs/glass-materials.md)。
- 新增「设置 → 中文译文」。主窗口与悬浮歌词各有独立开关，即时保存；中文以较小文字显示在对应原词下方，使用原来的动态时间轴和偏移。缺失、空白间奏与已确认纯音乐保持留白，切换时保留手动浏览状态。
- 增加来源译文查找、版本及完整原文对应检查、暂停/继续、重试和中文 LRC 修订；来源与 AI 属性保存在个人资料中。[中文译文说明](docs/chinese-translations.md)。
- 中文译文单独保存在个人 `translations.db`，绑定原词 SHA-256；原词修改后旧译文不会串用。个人备份新增译文 JSON 和一致数据库快照，保留来源、行号与 AI 标记；软件 ZIP 排除译文、模型和准备报告。

- 设置与悬浮外观面板改为可并行操作，调整主题时可直接拖动桌面歌词。编辑时临时解除点击穿透，关闭后恢复锁定/显示状态，保留主动调整的位置。

## 启动与升级

1. 从旧版托盘菜单选择“退出”。新数据库升级后请使用新版。
2. 完整解压运行包，双击 `Launch.vbs`。运行时随包提供，无需 SDK、管理员权限或 Apple API 密钥。
3. 在 Apple Music 正常播放。默认在后台预缓存本机完整资料库，主窗口可关闭到托盘继续工作。

首次歌词下载需要持续处理，耗时取决于资料库大小和服务可用性。服务繁忙、限流或没有可靠歌词时会分别记录并重试，不能将正在进行的扫描视为全库歌词已齐。已保存的歌词和封面可离线使用。

自定义位置可在“资料库”窗口选择 `Library.musicdb`。读取的是 Apple Music 已同步到本机的资料库；云端变化需先在 Apple Music 完成同步。原库、原封面和媒体文件不会被修改。

## 界面与悬浮歌词

应用主题在「设置 → 应用界面」选择：液态玻璃、毛玻璃、谷歌平面，即时保存；两种玻璃主题自动随当前封面取色，主界面保留播放和歌词阅读空间。

液态玻璃使用深色流光，毛玻璃呈现浅色柔雾；背景、光晕、高光和控件随封面协调变化，切歌时以 650 毫秒过渡。黑白封面呈现中性色，缺失封面恢复默认色；减少动画设置生效。谷歌平面保留固定丁香配色。

「设置 → 悬浮歌词」提供独立外观入口。悬浮窗、工具栏和外观编辑器使用自己的配色，不跟随应用主题。提供八种外观，以及字体、字重、字号、对齐、颜色、透明度、圆角、留白、行距、宽度、阴影和动效设置；各主题分别记忆，保存后重启仍保留，取消可恢复原样。[主题记忆指南](docs/theme-memory.md) · [主题指南](docs/ui-themes.md)。

- `Ctrl+Alt+L` 显示或隐藏桌面歌词，`Ctrl+Alt+U` 解锁。可在设置修改快捷键。
- 未锁定时拖动、调整大小或悬停显示工具栏；锁定后点击穿透。纯音乐时自动隐藏卡片且保持鼠标穿透。
- “更换歌词”、LRC/TXT 导入和偏移校准保留为手动修正入口。TXT 保持静态，不生成虚假时间轴。

## 来源、准确性与本地数据

[LRCLIB](https://lrclib.net/docs) 提供歌词候选；中文译文准备查询网易云音乐公开原词/译文接口，并保留来源。结构与元数据检查可以排除明显错误，不能证明每个字和每个时间点都准确，也不能保证所有歌曲均有可用歌词或翻译。[Apple 的公开 Song 属性](https://developer.apple.com/documentation/musickit/song)包含 `hasLyrics`，没有公开的歌词正文属性；第三方歌词不能标记为已经 Apple 逐首核对。没有结果也不会推断为纯音乐。AI 来源和原始校对状态继续保存在个人数据中，隐藏界面标志不修改记录；未确认的译文行留空。

个人数据默认保存在 `%LocalAppData%\LumaLyrics\`：`lyrics.db`、`artwork.db`、`translations.db`、封面缓存、设置、日志和准备进度。可在个人资料页导出独立文件或选择恢复后的数据目录；选择记录在程序之外，后续更新继续沿用。歌词数据库保持 v5，已有升级备份与手动绑定保留。[个人资料与软件的区别](docs/personal-library.md)。

原词查找向 LRCLIB 发送必要歌曲元数据；用户启动来源译文准备时，向网易云音乐公开接口发送歌名与歌手，并在本机检查返回的录音信息和原词。封面只读取 Apple Music 本地索引和 Apple 图片域名。请求串行节流，服务拒绝、限流或连续失败会停止本轮，已保存内容保留。不会上传资料库文件、账户、播放历史或音频，个人歌词、中文译文、封面、模型与缓存不提交 GitHub。本次 AI 译稿采用本地模型推理，不通过第三方在线翻译上传原词。

本机原有 apphost 启动停顿尚未确定原因，`Launch.vbs` 使用随包 Microsoft host。自包含包也需完整解压，不能单独移动 EXE。

## 构建与导入工具

Windows x64，C# 14，SDK 10.0.402，.NET 10.0.13，WPF。依赖版本固定。

```powershell
./scripts/build.ps1
./scripts/test.ps1
./scripts/publish-ui.ps1
```

开发工具支持 `--library`、`--library-status`、`--asset-status`、`--artwork <数据目录> [上限] [--retry]` 和 `--prefetch <数据目录> [上限] [--once|--drain] [--batch] [--retry]`。`--drain` 处理剩余队列后退出，缺失与网络错误保留，`--batch` 共享完整的小型歌手查询并保持串行；`--retry` 重置延期。正常使用直接由主程序后台导入即可。
