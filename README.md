# 浮光歌词 LumaLyrics 0.3.1

Windows 桌面歌词应用：Apple Music 负责播放，浮光歌词负责全库预缓存、自动查词、本地保存及透明悬浮显示。

## 本次优化

歌词切换加入淡入与上移，默认 220 毫秒，可在外观中调整或关闭。单行歌词居中，单双行切换保留当前句的屏幕位置；工具栏浮到卡片上方。圆角保留柔和透明边缘，主界面进度条和滚动条也统一美化。可点外观预览中的“试播切换”查看动画，详见 [0.3.1 说明与验证](docs/motion-v031.md)。

## 新版外观

点击顶部“外观”，可实时预览液态玻璃、雾面毛玻璃、Google Material 风格的浅色 / 深色、极光、暖纸、经典卡片与纯净透明，共八种主题。

支持系统字体、18–96 px 字号、四档字重、三种对齐、配色、透明背景、背景不透明度、圆角、留白、宽度、行距、次行比例/透明度、阴影强度及玻璃高光。保存到本机，取消恢复原样；背景变透明时文字不会一起变淡。

本机为 Windows 10：玻璃主题尝试系统背景模糊，不能等同 Apple 系统 Liquid Glass 的真实折射。系统不支持或关闭透明效果时使用半透明材质。详细说明及实图见 [外观指南](docs/appearance-v030.md)。

## 新版的自动流程

- 自动发现并只读本机 Apple Music 资料库。本机已完整读取 3,219 首，全部有歌名与时长，记录数量与资料库声明一致。
- 默认后台预缓存全库。匹配歌名、歌手、专辑、时长与录音版本，再检查歌词结构，自动保存到本地。
- 播放未缓存的新歌时自动查词和导入；日常无需逐首选择候选。同一录音的重复歌词记录按质量排序后自动选取。
- 顶部“资料库 已缓存/总数”显示进度，点击可暂停、继续或重试。已缓存项会跳过，关闭后下次断点继续；每五分钟检查资料库更新。
- 暂无可靠结果、歌词片段和网络错误保留为不同状态，后台重试，不弹窗要求确认。

完整性检查包括占位文本、时间戳数量与范围、后半段覆盖，以及同步歌词和来源纯文本的覆盖对照。它能筛除明显片段，但不能保证第三方文本百分之百完整或准确。没有公开歌词的歌曲不会凭空生成正文。

## 启动与升级

1. 从托盘选择“退出”，关闭旧版。
2. 完整解压运行包，双击 `LumaLyrics.exe`。无需 SDK、管理员权限、Apple API 密钥或导出资料库。
3. 自动读取本机资料库并开始后台缓存；在 Apple Music 中正常播放即可。

首轮 3,219 首需要持续后台处理，取决于服务和网络，尚未全部下载完成。已经找到的歌词立即存入本地，之后离线也能读取。保持程序在托盘运行即可继续预缓存。

自定义位置的资料库可在“资料库”窗口选择 `Library.musicdb`。读取的是本机已同步的资料库；云端新增曲目需 Apple Music 先同步到本机。该私有文件格式可能随 Apple 更新而变化，读取失败时会给出状态，不修改原库。

## 桌面歌词及可选修正

- `Ctrl+Alt+L` 显示/隐藏桌面歌词，`Ctrl+Alt+U` 解锁。快捷键可在设置修改，冲突时有提示。
- 未锁定时可拖动和调整大小；锁定后使用原生鼠标穿透样式。托盘始终提供解锁和恢复默认位置。
- 主窗口、悬浮窗和托盘均可打开独立外观面板；未锁定时悬停显示工具栏。
- 默认关闭主窗口后继续在托盘运行；明确退出会停止后台工作。
- 提前/延后按钮用于可选校准；正数表示歌词延后，负数表示提前。
- “更换歌词”及 LRC/TXT/粘贴导入保留为可选修正入口；正常匹配无需打开。已确认的手动绑定优先保留。
- TXT 保持静态，不生成虚假时间戳。播放控制只在 Apple Music 会话报告支持时启用。

## 本地数据与网络

数据位于 `%LocalAppData%\LumaLyrics\`：`lyrics.db`、`settings.json`、`library-prefetch-progress.json`、日志及缓存。队列和绑定持久保存。数据库升级至 v4，升级前生成一致备份 `lyrics.db.pre-v4.backup`。不要在迁移后重启旧版程序访问新库。

只向 [LRCLIB](https://lrclib.net/docs) 发送查词需要的歌曲元数据。串行节流，遵守 Retry-After，连续错误退避。可以关闭联网或暂停后台，不上传资料库文件、账号、播放历史或音频，不修改 Apple Music 资料库。

## 验证与限制

53 项自动测试通过，Release 构建无警告。此前实际读取 3,219 首并开始真实本地预缓存，完成自动导入、手动绑定保留及重启恢复检查。新版另验证八种主题、外观保存/取消、参数迁移和控件事件。预览示例与 QA 歌词均为自写文本。

全库下载尚在进行，不能视为全部歌曲均有正确歌词。同步仍受本机 GSMTC 整秒时间轴限制，暂定 B 级；多屏/DPI、两小时稳定性、实际跨进程点击穿透等完整验收仍待执行。

## 构建

Windows x64；SDK 10.0.402，.NET 10.0.13，WPF。源码分为 App、Core、Windows、Infrastructure 和 Probe，版本与依赖锁文件已固定。

```powershell
./scripts/build.ps1
./scripts/test.ps1
./scripts/publish.ps1
```

运行包自带运行时。`Launch.vbs` 是备用入口。`Probe.cmd` 采集约 180 秒 GSMTC 匿名轨迹。开发工具 CLI 也支持 `--library`（只读计数）、`--library-status`（缓存进度）、`--prefetch <数据目录> [本轮上限]`。全量预缓存进程可从资料库窗口暂停；程序退出会停止它。
